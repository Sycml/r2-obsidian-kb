这是直接从 **Cloudflare R2 私有存储桶** 实时读取并渲染的 Obsidian 知识库。无论在手机、平板还是电脑浏览器中打开，都可以获得一致且清爽的阅读体验。

> [!tip]+ 实时同步，无需重新构建
> 当你在本地 Obsidian 通过 **Remotely Save** 等插件将新笔记同步到 R2 存储桶后，只需点击右上角刷新按钮，网页端即可秒级看到最新内容。

## 多端使用建议

- [x] **电脑端**：享受左侧目录树 + 中间正文 + 右侧大纲（TOC）三栏联动
- [x] **平板端**：支持收起侧边栏专注阅读，随时唤出悬浮大纲
- [x] **手机端**：在 Safari / Chrome 中点击「添加到主屏幕」，即可作为独立 PWA App 随时查阅

> [!note] 隐私保护机制
> 你的 R2 存储桶保持 **完全私有**，无需开启 `r2.dev` 公开链接；所有笔记内容与图片附件均由 Cloudflare Worker 校验登录态后通过内部绑定代理返回。
